# jack-mods

[简体中文](README.md) · [English](README.en.md) · **Русский** · [فارسی](README.fa.md)

Мои моды для Claude Code.

Оба находятся рядом с названием модели под полем ввода: ⚡ quick-commands, 🪙 token-band (в свёрнутом виде).

![Кнопки на панели](docs/toolbar-buttons.png)

## token-band

Полоса над полем ввода, которая в реальном времени показывает расход токенов:

![Развёрнутый вид](docs/token-band-expanded.png)

Нажмите кнопку сворачивания, и полоса исчезнет целиком; справа на панели под полем ввода останется только 🪙. Нажмите на неё, чтобы развернуть снова:

![Свёрнутый вид](docs/token-band-collapsed.png)

```
271.1k/1.00M (27%) · this turn 3.3k · 113 tok/s · total in 7.92M · total out 38.4k · cache 98% · $8.58 · 5h 99% · 7d 70% ✅   [collapse]
```

> Подписи на полосе в скриншотах пока на китайском; строка выше показывает те же поля по-английски и в том же порядке.

| Поле | Значение |
|---|---|
| `271.1k/1.00M (27%)` | Текущий размер контекста / окно модели |
| this turn | Выходные токены этого хода; растут, пока идёт ответ |
| `tok/s` | Средняя скорость вывода: весь вывод ÷ всё время генерации (от первого до последнего токена, без ожидания первого) |
| total in / total out | Итоги за сессию, включая чтение и запись кэша и субагентов |
| cache | Доля входных токенов, взятых из кэша; чем выше, тем дешевле |
| `$` | Стоимость сессии |
| `5h` / `7d` | Израсходованная доля 5-часового / 7-дневного лимита подписки (при оплате через API не показывается) |
| `✅` / `❌` | Проверка модели: становится ❌ и показывает уведомление с причиной, если основной диалог переключили на другую модель, API вернул не ту модель, что запрашивалась, или уровень рассуждений незаметно понизили |

- В узком окне полоса переносится на две строки, а кнопка сворачивания остаётся справа в первой строке.
- Можно также ввести `/tokens`, чтобы переключаться между развёрнутым и свёрнутым видом.

## quick-commands

Добавляет кнопку ⚡ справа от названия модели. Она открывает боковую панель, чтобы не набирать `/xxx` вручную:

- **Вкладка «Команды»**: все слэш-команды текущей сессии (встроенные, ваши собственные, из плагинов и навыков, MCP), по группам и с поиском.
  - Частые встроенные команды (`/compact`, `/clear`, `/context`, `/cost`, `/resume`, …) запускаются одним нажатием.
  - Остальные (навыки, команды плагинов и MCP) только вставляют `/name ` в поле ввода, чтобы вы дописали аргументы и отправили сами. Ничего не срабатывает случайно.
  - `⋯` рядом со встроенной командой позволяет ввести аргументы; если вывод команды перечисляет «Available: a, b, c», мод запоминает это и в следующий раз показывает варианты кнопками.
- **Вкладка «Настройки»**: настройки `/config` в виде кнопок. Переключатели — «Вкл / Выкл», настройки с выбором — по кнопке на вариант, текст и числа — поле ввода. Текущее значение выделено синим.
- **Китайский / английский**: по умолчанию интерфейс следует `language` в `settings.json` или языку системы; кнопка 🌐 переключает «Авто / китайский / английский» вручную. Русского интерфейса пока нет.
- Нажмите ⚡, чтобы открыть; нажмите ещё раз (теперь ✕) или Esc, чтобы закрыть.

## Установка

### Что нужно

- Установленный [Claude Code](https://code.claude.com), команда `claude` работает в терминале. Моды работают и в терминале, и в приложении для компьютера.

### Установить оба (рекомендуется)

Вставьте в терминал:

```bash
claude plugin marketplace add crebot51/jack-mods && claude plugin install token-band@jack-mods && claude plugin install quick-commands@jack-mods
```

Команда добавляет маркетплейс `jack-mods` (нужно один раз), затем ставит оба мода для вашего пользователя, так что они будут во всех проектах.

### Установить только один

Один раз добавьте маркетплейс, затем поставьте нужный:

```bash
claude plugin marketplace add crebot51/jack-mods
```

```bash
claude plugin install token-band@jack-mods
```

```bash
claude plugin install quick-commands@jack-mods
```

### После установки

1. Откройте **новую** сессию. Уже открытая сессия сохраняет моды, с которыми запустилась; выполните в ней `/reload-plugins` или откройте новую.
2. Проверьте, что всё появилось:
   - **token-band**: полоса расхода над полем ввода. В приложении для компьютера появляется после первого сообщения.
   - **quick-commands**: ⚡ рядом с названием модели.

Посмотреть, что установлено:

```bash
claude plugin list
```

### Обновление

Загрузите свежий маркетплейс, затем обновите каждый мод:

```bash
claude plugin marketplace update jack-mods && claude plugin update token-band@jack-mods && claude plugin update quick-commands@jack-mods
```

Затем откройте новую сессию или выполните `/reload-plugins` в открытой.

### Удаление

Один мод: `claude plugin uninstall <name>@jack-mods`

Оба вместе с маркетплейсом:

```bash
claude plugin uninstall token-band@jack-mods && claude plugin uninstall quick-commands@jack-mods && claude plugin marketplace remove jack-mods
```

### Частые проблемы

| Что видно | Что делать |
|---|---|
| После установки нет ⚡ / полосы | Сессия была открыта до установки: выполните `/reload-plugins` или откройте новую сессию. |
| token-band ничего не показывает в приложении для компьютера | Отправьте одно сообщение; полоса появляется после первого хода. |
| `claude plugin install` пишет, что плагин не найден | Выполните `claude plugin marketplace update jack-mods` и повторите. |

> API модов — ранний предварительный выпуск; при смене версий Claude Code модам могут понадобиться обновления.
